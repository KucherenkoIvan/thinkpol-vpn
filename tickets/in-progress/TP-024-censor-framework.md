## Goal
A pluggable censor in the lab's router, and a runner that scores every transport against every censor module.

## Scope
- Censor program in the router container: nftables → NFQUEUE (pure-Go, e.g. `florianl/go-nfqueue`), per-flow tracking.
- Module interface: passive modules return a verdict per packet or flow (accept, drop, reset, throttle); active modules may act on their own (the prober).
- Modules switchable per test through config; verdict log available to tests.
- Matrix runner: each transport × each module → pass/fail, written to `lab/RESULTS.md` (generated, committed).
